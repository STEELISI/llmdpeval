You are given a csv file `auto_mpg_clean.csv`.

Write executable Python code to compute one differentially private query answer for the following task:

Query type: Linear Regression
Query definition: Fit a DP linear regression model using the specified predictor column to predict the outcome column. Then use the fitted model to predict the given test inputs.
Predictor columns: `weight`
Outcome column: `mpg`
Test inputs: [[200], [100], [4500], [10]]

Requirements:
1. Compute the true (non-private) prediction by fitting a standard linear regression model and predicting the outcome for the given test inputs.
2. Compute the differentially private prediction by fitting a differentially private linear regression model and predicting the outcome for the same test inputs.
3. Use the following privacy parameters:
    - epsilon = 1
    - bounds_x = (1500.0, 5500.0)  (public domain knowledge: the range of car weights in lb, not measured from the data)
    - bounds_y = (5.0, 50.0)  (public domain knowledge: the range of fuel economy in mpg, not measured from the data)
    - neighbouring relation: datasets differ by adding or removing one row (add/remove), so the number of rows is not public

4. Use the following DP framework: OpenDP.
5. Print both the true prediction and the differentially private prediction.
6. Return only executable Python code.
